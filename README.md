# Тестовое задание на позицию Senior Frontend Engineer

Описание тестового задания:

**Обмеження**

1. Стек: SolidJS
2. Заборонено зовнішні бібліотеки для віртуалізації — усе для списку реалізувати самостійно.
3. Код має бути написаний вручну — без використання AI для написання або редагування коду. Виняток — дозволено
   одноразово згенерувати фіктивні дані на 50 000 записів за допомогою AI та зберегти у JSON. Подальша робота з даними й
   уся логіка застосунку — лише вручну.

**Дані**

- 50 000 записів { id, name, price, updatedAt }. Генерація даних за допомогою AI.

**Функціонал**

- Власний хук`useVirtualList`для віртуалізації списку
- Клієнтське сортування: по`name`,`price`,`updatedAt`. Стабільність сортування — бажана
- Фільтри: за ціною, пошук за`name`
- Дебаунс пошуку — 250 мс без зайвих повторних рендерів
- Збереження та відновлення стану через URL ?query string: параметри:`sort`,`order`,`scroll`.
- Стан має коректно відновлюватися після Reload і під час навігації Back/Forward.
- Якщо після зміни фільтрів попередня позиція недійсна — скрол до початку.

**Що треба здати**

- Репозиторій з вихідним кодом.
- `README.md`
- Файл з даними`data.json`
- Опціонально — демо-посилання
